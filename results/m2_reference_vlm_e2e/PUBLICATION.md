# M2 public subset

Only source-controlled first-party M1 synthetic RGB and M2 overlays, reviewed source/tests and small JSON/Markdown are included. No third-party BlenderWorld image, Agent asset, model, credential, Base64 request body or CLI session log is included.

The public copy retains original raw model answers, frozen questions/coordinates, failures, nulls, reviewed:false and provisional/debug. Coordinator filesystem paths are made repository-relative; deleted temporary CLI directories use explicit placeholders. This path-only curation does not modify raw server files or establish stronger isolation. The published input PNGs have no ancillary metadata and retain the exact decoded M1 pixels.

Raw per-call reservation/ledger duplicates, duplicate Offline report/comparison, optional no-VLM control PNG and local dependency installation are withheld as redundant or machine-specific. The full VLM packet remains in verification_results.json and the planning packet in planning_response.json. The two M1 source renders/geometry/metadata/execution record remain in the prior published experiment; they were not regenerated or recertified.

This is an authorized feature-branch publication, not main integration or evidence review. M1 and older private/raw working-tree files were not staged or modified.
