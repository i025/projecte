# 本轮结论与静态视觉检查

**冻结 B2 的“减少矩形之间重叠”行为迁移到了两张新图；内容完整性和语义分组优势尚未得到跨场景验证，也出现了值得保留的裁剪风险。现有证据不能判定它只对 bw_0074 有效，更不能认定它已稳定泛化。** 两张新图都缺少适用的 VLM Region Plan，本轮只能运行非 VLM 缓存框的条件测试。

本文件为助手的原图静态检查记录，不是人工像素审核。所有候选继续 `reviewed:false`、`mask_reviewed:false`、`reliability:0`。用户对 bw_0074 的认可仅限区域粒度与大致完整性，没有转换成语义 GT 或正式评分授权。

## bw_9064

- 五个输入框是历史助手提出的后墙、顶棚、地板、左墙、右墙，不是已成功生成的 VLM 粗区域规划。
- 冻结 B2 将重叠从 **6.15% 降到 1.69%**，变化为 **−4.46 个百分点**。初始框已覆盖全图，B2 并集仍是 100%；没有添加任何区域像素，也没有为了达到覆盖率而补分背景。
- 后墙窗口基本未变，覆盖桌椅、盆栽和部分冰箱。它可以是宽上下文采样，但不能将框内全部内容标成“墙面”语义，更没有单独形成有意义的家具组评价区域。
- 墙/顶、墙/地的真实边界有透视斜线，粗直角缺口只减少矩形相交；角落中仍存在错误归属风险。保留下方家具的混合上下文不等于完成家具组定位。
- 结论：几何去重叠可复现；没有证据表明主要内容完整性优于矩形，Region-first 所需的语义分组仍缺上游 Plan。

## bw_0073

- 五个输入框是木地板、局部石材背板、右侧柜体、岛台台面、顶棚。它们是历史分割提示框，不是覆盖整幅厨房主要内容的粗区域规划。
- 重叠从 **2.29% 降到 0.74%**（**−1.56 个百分点**）；未分配比例从 **33.37% 增至 38.13%**（**+4.76 个百分点**）。未强制补分背景。
- 冻结词表不识别 `marble backsplash`、`cabinets`、`island countertop`，三类没有内容 bbox 护栏。本轮没有补充别名或阈值。
- p08 石材采样区面积减少 **43.5%**：减少了下沿柜面等混入，但同时收窄右边缘。它本来就只采样左侧背板，没有覆盖全场景石材；不能将面积缩小直接算成正确率提高。
- p10 岛台台面面积减少 **24.6%**，左侧台面部分被排除，是内容完整性的明确风险。p09 柜体面积减少 **16.3%**，靠近外沿的柜体内容是否应全部保留仍需审核。
- 地板 ROI 仍包含椅脚；四把椅子的上部、主要灯具、部分左侧和后方设施没有形成独立粗区域。这是输入框缺少内容组的问题，B2 只能向内调整，无法补全上游漏掉的评价区域。
- 结论：存在背景减少的局部收益，同时存在有效内容被裁剪的风险；不支持宣布“B2 内容完整性优势已迁移”。

## 模拟扰动的实际发现

最终有效数据为 **40 个共同支撑区域内扰动样本、576 条逐支撑测量**，另有 **2 个被 B2 排除区域的反向检查、21 条测量**。它们都是 RGB 编辑，不是真实 Agent 重建错误。

下表均为相对自身 Baseline 的 Appearance 变化。对应的全部有效数值 Baseline 为零。Dense Max 仅展示四个 Patch 中最大的局部读数，没有作为新聚合评分。

| 图片 / 模拟扰动 | 矩形 ROI Δ | B2 ROI Δ | Global Δ | Dense Max Δ |
| --- | ---: | ---: | ---: | ---: |
| bw_9064 后墙局部颜色 | 0.002659 | 0.002659 | 0.001273 | 0.004699 |
| bw_9064 地板局部颜色 | 0.005918 | 0.006593 | 0.001260 | 0.005041 |
| bw_0073 p08 局部颜色 | 0.020287 | 0.036352 | 0.000622 | 0.001739 |
| bw_0073 p10 局部模糊 | 0.007263 | 0.009640 | 0.000215 | 0.000860 |
| bw_0074 R1 局部颜色，对照 | 0.005052 | 0.007642 | 0.001219 | 0.004876 |

- 每个有效共同支撑扰动都在对应 ROI 内获得比 Global 更大的 RGB L1 变化。B2/Global 的倍率随区域大小变化，约 **2.09–58.42 倍**。这个倍率主要来自按支撑面积归一化，不能当作语义定位正确性的验证。
- 未扰动的其他 ROI 的 Appearance 最大变化是 **0**。Dense 单 Patch 有时比粗 Region 更敏感，例如 bw_9064 后墙；因此不能把 Region 一概描述为优于 Dense。
- Dense 的面积加权 RGB L1 平均与 Global 一致，实测最大绝对差 **4.34×10⁻¹⁹**。只看 Dense 平均仍然会稀释局部错误，逐 Patch 读数保留了局部信息。
- 三张图各有颜色、模糊两个 0.25/0.5/1.0 强度序列，共六组。Appearance 均随强度增大；Spatial、Statistical 在本组测试中非递减，但 bw_9064 的后墙 Spatial 始终为零。低纹理墙面的模糊反应很弱，不能据此伪造结构或语义错误。
- 颜色扰动在部分场景也引起 Spatial、Statistical 响应，来源包括 RGB 裁剪、灰度边缘变化和局部编辑接缝。二者共享边缘分布代理，响应存在重复；Statistical 没有获得真实物体密度或尺度真值。
- Semantic 与 Perceptual 全部为 N/A；没有新语义验证或 DINO 推理。没有 Observation、3D 或真实 Agent 还原分数。

### 被排除区域的反向检查

共同支撑方块天然避开了 B2 丢弃的区域，单独看这一组会低估漏评风险。因此另用同一几何规则，从 A 独占、且所有 B2 均未覆盖的位置各选一个可用小方块做颜色编辑。

- bw_0073 p08 排除区：A 的 Appearance Δ=**0.004453**，Global Δ=**0.000137**，Dense Max Δ=**0.000548**，所有 B2 ROI 的三项数值响应均为 **0**。
- bw_0074 R1 排除区：A Δ=**0.002342**，Global Δ=**0.000565**，Dense Max Δ=**0.002260**，所有 B2 ROI 响应均为 **0**。这里包含被合理排除的墙面，不能将零响应自动视为语义定位失败。
- bw_9064 没有足够大的 A-only 全局未覆盖区域，此项明确跳过。

这些方块的语义相关性未知，不能证明 B2 丢掉了重要物体；它们证明 Global/Dense 必须继续承担未分配区域的检查职责，也说明“ROI 内响应增强”不能排除内容漏评。

## 测试、失败记录与成本

- **113 项 CPU 单元测试通过**；新增边界回归检查确认贴边 ROI 的测试方块不会越界，颜色编辑必须实际改变像素。
- 首次扰动夹具未将图像外部计作边界，导致 6 个贴边测试没有实际修改图像。原始尝试保留在 `../region_first_generalization/`，其扰动数据不纳入本报告结果；未将它们当作模型或指标失败。修正仅涉及新实验的方块选择与边界检查，冻结 B2 未改动。
- 修正后复测 **40/40** 个样本均实际改变了图像像素；上述所有数字来自当前 `region_first_generalization_checked/`。
- 首次几何+扰动尝试约 **55.89 s**；复用相同几何后的有效扰动与产物生成约 **39.11 s**；反向检查为额外的轻量 CPU 计算。原始 B2 单图几何调用约 **0.178 s / 0.128 s**（bw_9064 / bw_0073）。时间不包括人工视觉检查和报告整理。
- 新增付费 API **0**，新增模型推理 **0**，GPU **0**。两次完整 VLM→ROI 新场景验证因缺 Plan 跳过；没有静默补造计划、调用 Agent 或运行 Blender。
- B2 源码按完整文本与快照直接比对一致，参数字典一致；没有哈希校验或额外版本管理。bw_0074 原有产物、原始 Run 和正式评分公式未改动。

## 下一步判断

当前保留 bw_0074 B2 为经过粒度/大致完整性人工确认的首选候选。对新图，现有结果只支持几何行为可运行和减少相交；不支持默认认定内容完整性已稳定泛化。下一步的有效证据应来自独立且适用的粗 Region Plan，再使用冻结算法比较；本轮不追加请求、不修补边界，也不扩展词表。
