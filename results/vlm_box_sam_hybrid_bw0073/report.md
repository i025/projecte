# bw_0073：Direct Box → SAM2 与 Hybrid ROI

**单个 BBox 提示不能保证 SAM2 输出完整功能区域。本图 R2 是明确失败案例：SAM 保留吊灯、摆物和部分椅子，却漏掉岛台主体，不能替换 Direct Box。R4 的柜体组边界更有价值；R3 有减少前景混入的迹象，但仍缺少内容完整性依据。**

Hybrid 按事先确定的统一规则，对四区都保留原始 Box 并标记 uncertain；本轮没有证据支持宣称 Hybrid 同时改善了完整性与背景控制。没有按 Region ID、名称或事后看图结果给 R4 单独放行。

- **A Direct Box：** 逐字节复制历史 `B_direct_box_native/R*.png`，作为完整性基线。Box 自身仍是待审核候选，并非完整性 GT。
- **B Box → SAM2：** 未找到可直接复用的官方 `SAM2ImagePredictor` 源码，复用已有 `benchmark.evidence.sam2_box_masks`，由 Transformers `Sam2Model/Sam2Processor` 从本地 `/home/xymo/models/sam2` 加载。一次原图调用包含四个 Box，`multimask_output=False`，每框保存一张实际原始候选及原始 IoU-head score。没有多个候选的合并、抠洞修补、形态学清理或 Box 裁剪；Box 外延伸同样保留。
- **C Hybrid：** Box Prompt、模型分数、面积比例及连通性都不足以证明多对象功能区完整。缺少独立完整性依据时，不批准删除 Box 内像素，输出原始 Box 的副本和 uncertain 决策。候选规则不接收 Region ID、区域名称或场景专属阈值。

历史 SAM2 缓存使用了椅子、台面等其他框，没有与本轮四个 Direct Box 精确匹配的结果，所以没有冒用缓存。未运行 SAM3，也未把 SAM3 exemplar 提示与本轮 SAM2 局部 Box 提示混为一谈。

| Region | A Direct Box | B SAM2 原始输出 | C Hybrid |
| --- | --- | --- | --- |

`initial_review.json` 是助手静态诊断；`review_checklist.md` 是尚未填写的人工审核材料。两者都没有将候选设为审核通过。

原始 SAM 并不严格限制在 Box 内：R1 有 **42324** 像素、R4 有 **4278** 像素延伸到 Box 外；R2/R3 为 0。没有悄悄裁剪这些输出。`differences/` 保存每区原分辨率的“Box 中被 SAM 删除”和“SAM 在 Box 外延伸”二值图及 Overlay。删除像素同时包含可能的背景和重要内容，不能直接当作背景标注。

## Hybrid 能证明什么

本轮 C 只是一个明确、保守的候选决策：**证据不足时回退 Box**。它不是新的边界优化算法，也没有实现同时减少背景并保证完整性的自动选择器。

R4 在静态初审中看起来更合适，但若据此只替换 R4，就变成了人为挑选。R3 看起来减少了部分前景，仍无法证明所有描述内容被保留。未经审核不能凭高分、低重叠或轮廓好看就批准替换；因此四区采用同一规则。

## 对五个问题的回答

1. **BBox 提示能否分割完整功能区域？** 有时能形成有用的连续候选，不能保证完整。R2 是明确反例，且实际丢失模式不能由“只选一个物体”的预设代替检查。
2. **哪些更适合 SAM？** 本图 R4 柜体组最值得人工检查，R3 可作为边界辅助候选；R2 应保留 Box，R1 也有内容缺口与背景混入。这里的判断不是新规则，也没有触发自动替换。
3. **Hybrid 能否兼顾完整性和背景？** 本轮没有证明。它成功避免无依据删除，但四区均回退 A，背景排除没有获得改善。
4. **SAM 值得作为正式可选步骤吗？** 可作为按需候选生成和人工审核辅助，特别是单一连续柜体等区域；当前不宜自动替换所有功能区 Box，更不能作为默认必经步骤。正式流程未改动。
5. **是否研究更多 Point/Box Prompt？** 本轮没有证据表明它是下一阶段局部评价的前置条件。先审核粗 ROI 并验证下游局部错误检测更有必要。只有明确出现需精细边界或可分离组成部分的需求时，再有限研究多提示；多提示也仍需完整性判定，不能盲目取并集。本轮没有追加提示或第二轮推理。

## 实际资源、警告与检查

- 没有付费 VLM 请求、Region Planning、SAM3、DINO、SLIC、Blender 或 Agent 执行，没有正式评分、依赖下载或共享环境修改。
- 初始默认沙箱无法访问 NVIDIA 驱动；只读沙箱外检查确认 GPU 0 空闲，另一个用户使用 GPU 6。本轮仅使用单张 GPU 0；执行前两次检查间隔约 3 秒，均为 0 MiB、0% 利用率、无进程。执行期间同卡进程只有本次 worker。
- 一次 SAM2 调用、四个 Box，原始候选 **4 张**，没有自动重试。CPU 线程 2，显存上限为单卡 20%，进程超时 180 秒。
- 前向推理 **0.493 s**；包含模型加载、前向及原分辨率后处理的调用墙钟 **4.183 s**，不包含后续 CPU 可视化。PyTorch 峰值分配 **434.27 MiB**、峰值预留 **668 MiB**；NVIDIA 进程/上下文总用量约 1181 MiB，二者口径不同。
- 加载时出现 `sam2_video` 配置实例化 `Sam2Model` 的提示，保存于 `model_load_warning.txt`。这是既有静态图像适配器使用方式；实际 missing/unexpected/mismatched keys 和 error_msgs 均为空，没有忽略新错误或更换模型权重。它仍是本轮实现范围的限制，不代表比较了官方独立 Predictor 的全部模式。
- **132 项 CPU 测试通过**，包括功能区分离组成部分保留、SAM 外溢不能扩大 Hybrid、缺失候选回退、网格不匹配拒绝，以及原始/Hybrid/删除像素分开保存和现有 Evidence 加载器检查。
- 原始尺寸、Plan/Box 与历史文件一致性、四张 SAM 原始二值图、12 张候选 Mask 与 8 张差异 Mask、全部审核字段、HTML 图像链接与无 GPU 离线重放检查见 `validation.json`。没有人工 GT，不报告 IoU、Boundary F1 或真实分割准确率。
